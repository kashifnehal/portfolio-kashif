# Asset Requirements

This is a requirements list for an original Kashif Nehal portfolio implementation. It does not authorize copying or redistributing assets from the reference site.

| Asset type             | Requirement                                                                  | Reference evidence                                                                                                                           | Safe implementation source                                                                                                                                         |
| ---------------------- | ---------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Hero background        | High-resolution, responsive artwork or photograph with a crop-safe subject   | Reference uses a WebP hero image, rendered as a cover-like background on desktop/tablet and hidden as a desktop background layer on mobile   | User-owned photography, commissioned artwork, or a properly licensed stock/open asset                                                                              |
| Project images         | One high-resolution image per project, with responsive crop-safe composition | Five project WebP images; lazy-loaded image elements; cover/object-fit behavior; 50% horizontal and 0% vertical background position observed | User-provided project screenshots/images or authorized original assets                                                                                             |
| Awards images          | Narrow award/project thumbnails for list rows                                | Award list contains lazy image elements and repeated list entries                                                                            | User-owned screenshots or omit the image treatment                                                                                                                 |
| Decorative star/symbol | Small transparent decorative raster or CSS/icon equivalent                   | `star.png` loaded at 174x174 intrinsic size and rendered around 28-40px in inspected desktop state                                           | Original CSS shape, open icon, or user-owned SVG/raster                                                                                                            |
| WebGL/3D scene         | Optional interactive visual layer                                            | `canvas.webgl`, Three.js/WebGL bundle code, Draco loader, and canvas rendering found                                                         | Original Three.js scene or omit unless it adds meaningful value; no reference model/texture reuse                                                                  |
| 3D model/textures      | Optional source for WebGL scene                                              | Draco request indicates compressed 3D decoding; exact model and textures not established                                                     | Original model or licensed asset; exact reference model is `Not yet verified`                                                                                      |
| Icons                  | Navigation arrows, back control, and status symbols                          | 19 inline SVG elements and an inline SVG back control observed                                                                               | Lucide/open icons or original SVGs; preserve accessible labels                                                                                                     |
| Fonts                  | Display, body, and optional decorative typefaces                             | Tusker Grotesk, Neue Montreal, Migra, and Maelstrom loaded from reference                                                                    | Licensed fonts if purchased; open alternatives: Bebas Neue/Archivo Black for display, Space Grotesk/Inter substitute for body, Cormorant Garamond for serif accent |
| Video                  | None required by observed reference DOM                                      | No `<video>` elements found                                                                                                                  | Not required unless original portfolio content needs it                                                                                                            |
| Cursor asset           | No custom cursor asset established                                           | No custom cursor file was identified in resource inspection                                                                                  | Native cursor or an original accessible CSS cursor treatment                                                                                                       |
| Background texture     | No separate texture file established                                         | Dark photographic layers and color overlay observed; separate texture source unknown                                                         | CSS texture or user-owned/licensed raster if needed                                                                                                                |

## Asset handling requirements

- Store portfolio-owned assets in the application asset area and keep paths in centralized data/configuration.
- Use responsive image sizing and explicit `alt` text or an empty alt for purely decorative images.
- Keep source dimensions, crop intent, and ownership/license notes with each final asset.
- Do not download or redistribute the reference site's fonts, artwork, project images, logos, or personal identity assets.
